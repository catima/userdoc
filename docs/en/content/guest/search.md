All CATIMA databases have their own search feature that can be used to search content with the help of keywords. The search engine provides a range of option which go from a simple search based on a single keyword to advance searches which may specify what keyword should be found in which field and may exclude content with a certain keyword as well.  

The search engine is accessible through the catalog's main page.  
> To access the homepage, click on the catalog's name on the left side of the navigation bar.
