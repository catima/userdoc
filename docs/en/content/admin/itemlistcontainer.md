Displays all items of an item type in a list, grid, thumb or line style (e.g. to show a list of all *Universities*). Different styles are :

> **Note**: it is not possible to have more than one Item List container on the same page.

![i](assets/pages/item-fields.png)

First select a unique slug, then define the item type to display, finally choose the appropriate sort order: alphabetical (*ascending* or *descending*), by creation date or by modification date. 
With *grid, list and thumb* styles, the sort order is defaulted to the primary field. When using the *line* style, you can choose which field to sort on.

> **Example**: let's say we have an item type **Book** with the following fields: *Title* (primary field), *Author*, *Publishing date* and *Illustration*. When choosing grid, list or thumb style sorting is done on *Title*. With line style it can be on *Title*, *Author* or *Publishing date*. *Illustration* will not be a possible choice as it can't be alphabetically sorted.

#### Line style

![i](assets/pages/line-open.png)

This style displays the items vertically along a line. The user can choose to see the items in an ascending or descending order and to see all the items or none with *Close all* and *Open all*. It is then possible to only see some of the items using the small arrows.

![i](assets/pages/line-closed.png)
