Can be used to add short (*e.g. name or title*) or long (*e.g. description*) text. It is possible to choose between a formatted text editor or a simple text editor.

> **WARNING** : once you defined text as fomatted, you should not untick the box **"Contains formatted text"**. Indeed, as you format the text with the editor, code is added to the field. Thus, if you shift back to unformatted text, the text may become crowded with strange encodings. Ticking that bxo will render the text correctly again.

Standard formatting (bold, italic, bullet points, footnotes) is done with icons that you are used to (e.g. in Word); in a few cases, you can select options with buttons:

![](assets/setup/formatted_text_editor.png)

>  **Note** :If this field is used as a primary field, formatted text is not possible and will be deactivated.

#### Options for new lines
In the formatted mode, you have two options for defining a new line:

1. By default, when you press **ENTER** on your keyboard, you will add a **new paragraph**. In that case, you automatically obtain a space between two paragraphs (*this is equivalent to `<P>` in HTML code*). 
2. As you presss **SHIFT + ENTER**, you'll add a **new line without any space** (*or equivalent to `<BR>` in HTML code*).
