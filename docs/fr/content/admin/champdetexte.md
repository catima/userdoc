Ce champ permet d'entrer du texte, qu'il soit court (p.ex un nom ou un titre) ou long (p.ex texte descriptif)

> L'option **"Contient du texte formaté"** propose un éditeur de texte prenant en charge des options de mise en forme.

> **AVERTISSEMENT** : une fois du texte formaté ajouté, il est **vivement déconseillé** de décocher la case **"Contient du texte formaté"**. En effet le formatage du texte ajoute du code informatique, et la désactivation de cette option affichera ce texte peu lisible à l'utilisateur. Recocher la case permet de rétablir l'affichage du texte formaté.

La mise en forme (gras, italique, listes, notes de bas de page) s'effectue à l'aide d'icônes classiques comme dans Word ou à l'aide de boutons expliquant clairement la fonctionnalité:

> **Note** : Les **champs primaires** ne peuvent pas être formatés (option "Texte formaté" grisée)

#### Options de retours à la ligne
Dans l'éditeur de texte formaté, vous avez deux possibilités concernant le retour à la ligne:

1. Par défaut, en sélectionnant la touche **ENTER**, vous ajoutez un **nouveau paragraphe**. Vous obtenez ainsi automatiquement un espace entre les deux paragraphes (*l'équivalent `<P>` en code HTML*). 
2. En maintenant les touches **SHIFT + ENTER** appuyées,vous avez la possibilité d'ajouter un **retour à la ligne sans espace**, aussi appelé *retour de chariot* (*l'équivalent `<BR>` en code HTML*). 

![](assets/setup/edit_WYSIWYG_BR_or_P.png)
