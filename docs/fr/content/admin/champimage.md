Ce champ permet d'ajouter des fichiers images, avec:
- (optionnel) une légende

![](assets/setup/new_field_image_legend.png)

- (optionnel) des restrictions d'extension; par exemple uniquement .jpg ou .png.

![](assets/setup/new_field_image_legend1.png)

**Formats haute-fidélité (TIFF et HEIC)**

Lors du téléchargement d'une image TIFF ou HEIC dans un champ de type image, le fichier est
converti au format JPG et sauvegardé en JPG dans Catima pour
permettre aux navigateurs web de les afficher. 

> **A noter**: s'il est nécessaire de sauvegarder les fichiers TIFF et HEIC dans leur format original, il faut les ajouter également dans un champ de type fichier.
